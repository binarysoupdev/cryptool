# Cryptool | [![GoDoc](https://godoc.org/github.com/binarysoupdev/cryptool?status.svg)](https://pkg.go.dev/github.com/binarysoupdev/cryptool)

Cryptool is a simple encryption tool for encrypting, decrypting, and generating keyfiles. It utilizes both the AES encryption standard and PBKDF2 for password-based key support.

Developed in association with [`"The Exciting Ecosystem of Encryption"`](https://www.youtube.com/watch?v=0G-2emH1-JU) project on the [`@binarysoupdev`](https://youtube.com/@binarysoupdev) YouTube channel.
