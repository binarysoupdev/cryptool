# Cryptool

Cryptool is a simple encryption tool for encrypting, decrypting, and generating keyfiles. It utilizes both the AES encryption standard and PBKDF2 for password-based key support.

Developed in association with [`"The Exciting Ecosystem of Encryption"`](https://youtube.com/@binarysoupdev) project on the [`@binarysoupdev`](https://youtube.com/@binarysoupdev) YouTube channel.
